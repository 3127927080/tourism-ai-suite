## 五、启动与联调步骤（复核用）

```powershell
# 8001 tourism
cd tourism-service; uv run python -m tourism_service.server
# 8002 ai
cd ai-service; uv run python -m atguigu.main
# 8000 CS 三进程
cd customer-service
uv run python -m atguigu.main
uv run python -m atguigu.worker.ai.worker
uv run python -m atguigu.worker.realtime
```

- 建表（幂等）：各服务 `uv run python -m atguigu.infrastructure.init_db`
- 取 token：`POST http://192.168.200.188:8001/api/v1/auth/demo-token`（`{"user_id":"user_001","role":"customer"}`）
- 发消息：`POST http://127.0.0.1:8000/api/v1/chat/messages`，body `{"message_id":"...","type":"text","content":{"text":"..."}}`

## 六、注意事项（踩坑记录）

- **中文请求体必须 UTF-8**：PowerShell 5.1 `Invoke-RestMethod` 默认编码会把中文变 `?`，需 `[Text.Encoding]::UTF8.GetBytes($json)` + `charset=utf-8`。服务端存库正常。
- **思考模式**：`LLM_THINKING_MODE=enabled` 显著提升结构化输出稳定性；`openai_compatible` 分支通过 `extra_body.thinking.type` 生效。
- **写操作边界**：AI 只读 + 页面引导；退款/取消/改出行人由前端确认后调 tourism 写接口。
- **TaskState**：CS 只存不透明 JSON，语义在 AI 归约；按版本原子写回、超时清空。
